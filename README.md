### 1. What is Version Control?
Version Control is like an **"Undo" button** for your whole project. It saves old versions of your work so you can easily go back if you make a mistake.

### 2. What is Git?
Git is a **smart notebook** on your computer that keeps track of every single change you make to your files.

### 3. What is GitHub?
GitHub is a **magic cloud folder** on the internet where you save your Git notebook so your instructor and friends can see and work together on it.

### 4. What is Git Bash?
Git Bash is a **special typing box** (terminal) on Windows where you can give simple text commands to Git.

### 5. What are the Main Parts of GitHub?
**Repository (Repo):** Your main project bag where all files and history live.

**Commit:** Taking a quick photo (snapshot) of your work to save it.

**Branch:** A secret practice paper to try new ideas without spoiling the main work.

**Pull Request (PR):** Asking your team, "Can I add my practice work to the main project?"

**Issues:** A sticky note list of bugs to fix or tasks to complete.

**Fork:** Making your own copy of someone else's project bag to work on.
